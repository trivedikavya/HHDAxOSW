# Demo Task CLI

A tiny command-line tool for managing a local task list. This repository
is bundled with RepoMedic AI as a demonstration fixture, so you can see
how the scanner works without uploading your own ZIP first.

## Installation

```
npm install
```

## Usage

```
npm start
```

## Development

```
npm run build
npm run format
```

See [the usage guide](docs/USAGE.md) for more examples and configuration
options.
